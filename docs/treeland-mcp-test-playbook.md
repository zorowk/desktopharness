# Treeland MCP 人工式 GUI 测试剧本

只测试系统已有应用的真实用户操作，不使用 testbench、定时器或 `PASS` 包装窗口。

## 通用规则

1. 以测试通过和可审计为目标。MCP、shell、`wlr-randr`、`wl-copy`、`wl-paste`、`treeland-debug` 或其他本机可用工具均可用于准备环境、驱动操作、观察和恢复；报告必须记录实际使用的工具、命令与观察证据。
2. 每项开始前确认所需应用和硬件可用；不满足时记录 `skipped`。AT-SPI 不属于前置条件。
3. 每个编号步骤是一个可观察的 GUI 阶段。只有该步骤的阶段完成条件已经由屏幕或窗口树观察到，才能进入下一步；不要因前一子动作已完成而跳过同一步中的后续动作。
4. 中文输入法切换使用 `Ctrl+Shift`。一旦观察到中文输入状态，需要英文输入时，按 `Ctrl+Shift` 强制切回英文输入状态并观察确认。
5. 每项结束后关闭本项创建的窗口、恢复显示或输入法状态、清理临时文件，再调用 `gui_run(operation="reset", task_id=<ID>)`。
6. 任一步骤的阶段完成条件尚未达成时，必须停留在当前步骤继续尝试；不得直接记录 failed，也不得跳到下一步。主控应在合同的 `max_steps` 和 `max_retries` 预算内继续观察，并让 Qwen 根据当前界面尝试另一条可见 UI 路径（例如从点击结果改为键盘激活）。仅在预算耗尽时记录 failed，或在前置条件不满足时记录 skipped。
7. 需要在文件选择器通过位置栏打开已知路径时，先用 `wl-copy` 将完整路径写入剪贴板；然后依次执行 `Ctrl+L`、`Ctrl+A`、`Ctrl+V`、观察位置栏、`Enter`。`Ctrl+A` 是必需动作：必须先全选并替换旧路径，不得在旧路径中插入或追加文本。只有位置栏视觉上显示完整目标路径时才能按 Enter；否则留在本步骤重试。

## TMC-101：启动编辑器、输入并保存文档

前置条件：应用启动器和系统编辑器可用；`/home/uos/DesktopHarness-Test/` 可写；`/home/uos/DesktopHarness-Test/treeland-mcp-test-playbook.md` 可打开。

1. 按 `Super`（Meta）键打开应用启动器，在搜索框中输入 `Text Editor`（中文界面名称为“文本编辑器”）并回车打开。阶段完成条件：编辑器为活动窗口。
2. 在编辑器按 `Ctrl+O`。阶段完成条件：文件选择器为活动窗口。
3. 用 `wl-copy` 复制 `/home/uos/DesktopHarness-Test/treeland-mcp-test-playbook.md`，在文件选择器依次按 `Ctrl+L`、`Ctrl+A`、`Ctrl+V`；确认位置栏完整显示该路径后按 Enter。阶段完成条件：编辑器重新成为活动窗口，且窗口标题包含 `treeland-mcp-test-playbook.md`。
4. 从可见正文中选择一个完整的短段落，关闭参考文档后新建文档并逐字输入该段落。阶段完成条件：新文档为活动窗口，且 Qwen 视觉确认输入文本完整。
5. 用保存对话框将新文档保存到 `/home/uos/DesktopHarness-Test/TMC-101.md`。阶段完成条件：窗口标题包含 `TMC-101.md`。

通过：Qwen 在编辑器正文中视觉确认所选段落完整且保存成功；编辑器为活动窗口，窗口标题包含 `TMC-101.md`。可用时再以 AT-SPI `document.text` 精确比对。

清理：关闭文档和编辑器，删除 `/home/uos/DesktopHarness-Test/TMC-101.md`，关闭启动器。

## TMC-102：单屏幕分辨率修改并恢复

前置条件：控制中心可用；图形会话内的 `wlr-randr` 显示恰好一个启用输出，并为该输出列出当前模式之外的至少一个可用分辨率。开始前记录输出标识、当前分辨率和缩放。任一条件不满足则 skipped；本用例不测试双屏、扩展、镜像或主屏切换。

1. 打开控制中心。阶段完成条件：控制中心为活动窗口。
2. 打开显示设置并选择唯一启用的输出。阶段完成条件：界面中可见该输出的分辨率选项和记录的当前模式。
3. 从界面列出的模式中选择任意一个与记录基线不同的分辨率并应用，等待桌面稳定。若出现认证或解锁对话框，在图形界面完成解锁后回到当前步骤继续；认证框本身不构成 failed 或 skipped。阶段完成条件：控制中心界面和只读 `wlr-randr` 都显示所选的新模式。
4. 在同一显示设置选择记录的基线分辨率并应用，等待桌面稳定。若再次出现认证或解锁对话框，同样在图形界面完成解锁后继续。阶段完成条件：控制中心界面和只读 `wlr-randr` 都显示记录的基线模式。

通过：两次模式切换均有控制中心的可见状态和 `wlr-randr` 的当前模式作为证据；最终仍只有一个启用输出，分辨率和缩放恢复为记录的基线。

清理：关闭控制中心和设置对话框；再次运行 `wlr-randr` 确认输出、分辨率和缩放仍为记录的基线。

## TMC-103：切换中文输入法并输入中文

前置条件：文件管理器可用；已启用中文拼音输入法；切换快捷键为 `Ctrl+Shift`；候选面板可见；`/home/uos/DesktopHarness-Test/` 可写。任一条件不满足则 skipped。

1. 通过启动器打开 `File Manager`（中文界面名称为“文件管理器”）。阶段完成条件：文件管理器为活动窗口。
2. 用 `wl-copy` 复制 `/home/uos/DesktopHarness-Test/`，在文件管理器依次按 `Ctrl+L`、`Ctrl+A`、`Ctrl+V`；确认位置栏完整显示该路径后按 Enter。阶段完成条件：测试目录内容可见。
3. 新建文件夹并使名称输入框获得焦点。阶段完成条件：文件管理器中显示可编辑的新文件夹名称输入框。
4. 在名称输入框键入探测串 `zhongwen` 并观察：出现拼音预编辑文本和候选面板才证明当前是中文输入法；若只出现字面 ASCII 文本，则先 `Ctrl+A` 清空、按 `Ctrl+Shift`，再重复探测。阶段完成条件：可见候选面板和拼音预编辑文本；不得仅以 Dock 图标或快捷键已送达为依据。
5. 取消探测预编辑并清空名称框，用拼音输入 `zhong wen shu ru fa ce shi`；在每次候选面板出现时根据可见候选选择并提交，最终文件夹名称必须为 `中文输入法测试`。阶段完成条件：文件管理器视觉确认完整文件夹名为 `中文输入法测试`。
6. 进入另一个临时文件夹的名称输入框，按 `Ctrl+Shift` 后键入探测串 `englishprobe`。只有直接出现字面 ASCII、没有拼音预编辑和候选面板才证明英文输入已恢复；随后取消该临时创建。阶段完成条件：可见的 ASCII 探测结果且无候选面板。

通过：Qwen 视觉确认候选面板选择正确，且文件管理器中完整显示 `中文输入法测试`。Dock 输入法图标只能作为视觉线索，不能单独作为断言；可用时再以 AT-SPI 精确比对。

清理：删除本项创建的 `中文输入法测试` 文件夹，恢复原输入法并关闭文件管理器和候选面板。

## TMC-104：多窗口切换与窗口状态保留

前置条件：系统编辑器和文件管理器可用。

1. 通过启动器启动 `Text Editor`，新建文档并输入固定 ASCII 文本 `Treeland window state test`。阶段完成条件：编辑器为活动窗口，且 Qwen 视觉确认短文本完整。
2. 将文档保存到 `/home/uos/DesktopHarness-Test/TMC-104.txt`。阶段完成条件：编辑器标题包含 `TMC-104.txt`。
3. 通过启动器启动 `File Manager`（中文界面名称为“文件管理器”）。阶段完成条件：文件管理器为活动窗口。
4. 用 `wl-copy` 复制 `/home/uos/DesktopHarness-Test/`，在文件管理器依次按 `Ctrl+L`、`Ctrl+A`、`Ctrl+V`；确认位置栏完整显示该路径后按 Enter。阶段完成条件：该目录内容可见。

清理：关闭本项创建的文件管理器、编辑器和任务视图，删除 `/home/uos/DesktopHarness-Test/TMC-104.txt`。

## TMC-105：跨应用复制粘贴

前置条件：系统编辑器和终端或第二个编辑器窗口可用；`/home/uos/DesktopHarness-Test/treeland-mcp-test-playbook.md` 可打开。启用 `wl_clipboard` evidence provider；测试前的剪贴板必须是可恢复的纯文本，否则 skipped。

1. 打开源编辑器并按 `Ctrl+O`。阶段完成条件：文件选择器为活动窗口。
2. 用 `wl-copy` 复制 `/home/uos/DesktopHarness-Test/treeland-mcp-test-playbook.md`，在文件选择器依次按 `Ctrl+L`、`Ctrl+A`、`Ctrl+V`；确认位置栏完整显示该路径后按 Enter。阶段完成条件：源编辑器标题包含 `treeland-mcp-test-playbook.md`。
3. 选择并复制一个完整、可见的段落。阶段完成条件：只读 `wl-paste` 读出的 `clipboard.text` 与该段落一致。
4. 启动或切换到目标应用并粘贴。阶段完成条件：Qwen 视觉确认该段落完整出现。
5. 回到源编辑器，选择并复制另一个不同的可见段落。阶段完成条件：只读 `wl-paste` 显示的新文本与第一次不同。
6. 切换到目标应用并再次粘贴。阶段完成条件：Qwen 视觉确认第二段完整出现，且不是旧内容。

通过：每次复制后由 `wl-paste` 读取的 `clipboard.text` 与当前参考段落一致；Qwen 视觉确认两段参考文本均完整出现，第二次粘贴不是旧内容。可用时再以 AT-SPI 精确比对。

清理：关闭源/目标应用和临时文档；用 `wl-copy` 恢复测试前保存的纯文本剪贴板，不清空测试前已有的用户剪贴板。
